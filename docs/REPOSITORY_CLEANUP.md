# Repository consolidation and preservation

Completed 5 November 2026. This is a documentation/report cleanup, not a development or acceptance milestone. Application behaviour, source/resources, tests/fixtures, Gradle/wrapper/dependency definitions, Firebase configuration, complete rules/indexes and the guarded acceptance launcher are unchanged.

## Classification and backup

The initial inventory contained 543 tracked and 41 nonignored untracked files. Every project-owned candidate was classified before removal. Required source/build/test/security/tooling and the four unrelated user files were retained. Historical reports, review manifests, draft collections and galleries were superseded only after their meaningful evidence and selected assets were consolidated.

A uniquely named **private external ZIP** includes all 955 files proposed for deletion or replacement, repository-relative paths, sizes, SHA-256 and reasons, plus inventory/manifest records (957 ZIP entries). CRC validation, archive-byte/source-hash comparison and a full extraction/re-hash passed. It is outside this repository and must never be uploaded. Its local path/hash is returned to the user rather than embedded here. A first verified backup preceded README replacement; the final union backup carries those original bytes plus the task-generated bytecode cache.

## Removed and retained

- **316 tracked obsolete files:** 284 historical gallery/design files and 32 root milestone/report/review-manifest files. The [full tracked retirement/replacement inventory](cleanup-inventory.json) records their reasons and original hashes. Git history remains available; it was not rewritten.
- **638 untracked/ignored obsolete files:** superseded 35-page drafts/assets/map/checklist, retired acceptance-only snapshot/writer folders, report intermediates/generators, project-local diagnostic logs and Python bytecode. These are private diagnostic copies, not actual app/emulator storage. Total removed:954; the remaining backed-up file is the replaced root README.
- Kept every production/debug/test source and resource, all unit/Android/Firestore tests, Firebase/rules/index tooling, Gradle files and wrapper, and `tools/acceptance/isolated_review.py`. Removing galleries does not remove screenshot-test fixtures: tests generate their own output and do not read these galleries.
- Kept the two original specification/requirements PDFs, canonical 17-page report/source/DOCX, selected screenshots, editable corrected figures, requirements map and consolidated verification. One project-maintained root README is authoritative; the two nested project READMEs were consolidated and retired. Third-party/vendor READMEs were not altered.
- Preserved `.vscode/settings.json`, `reporting-review-fixes.diff`, `savings-goals-deadline-fixes.diff` and `savings-goals-recovery-fixes.diff` untouched and uncommitted. Local configuration/credentials remain ignored and unchanged.
- SDK/AVD/emulator files, app/Gradle/global/vendor caches and local runtime/networking/DNS helpers were not cleaned. Other ignored local tooling was retained where safe obsolescence was not established. No device, storage, recovery or host configuration was modified.
