Editing does not move a record because updatedAt changed. The metadata is **@Transient**, so both financial payload maps and durable Gson operation JSON remain byte-equivalent with/without it. No new persisted field, rules, write protocol, arithmetic, queue identity or index is introduced. The user approved this specific read-only model/repository exception; local button-tap time is not reconstructed or added.
